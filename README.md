# Longsite Labs

Landing page for Longsite Labs LLC — https://longsitelabs.com

A single static page (`index.html`). No build step, no framework.

## Deploy

Hosted on Cloudflare Pages (free tier), connected to this repository.
Custom domain: longsitelabs.com (DNS at Porkbun).

Mail (`hello@longsitelabs.com`, Namecheap Private Email) is separate —
do not touch the MX / SPF / DKIM / DMARC records for longsitelabs.com.
